# 生活日报 · 手写报纸预览

可交互的设计预览，未接入网站路由或真实账户数据。

打开 `index.html` 可预览完整页面；`daily-paper.fragment.html` 是对应的可编辑看板片段。二者包含相同的设计与交互。

## 设计

- 使用原纸张版本的「生活日报」报头、旧纸纹理和暖色纸面。
- 正文采用霞鹜文楷，呈现清晰的手写感。
- 内容按独立区块自动排版，桌面三栏、中等宽度两栏、手机单栏。内容展开、收起或变化后会重新排列，避免相邻区块等高造成的大块空白。
- 保留今日纪事、尚未完成、学习与成长、收支、身体与饮食、随笔、补记和可选复盘等日报内容。

## 交互范围

支持日期切换、档案搜索、目录跳转、来源面板、补记保存、配图开关、复盘展开、复制与文本导出。页面使用示例数据；补记等状态仅保存在当前预览环境。复盘内容为预设示例。

纸张、报头和配图已嵌入文件。字体与图标通过在线资源加载；离线时字体使用系统楷体回退。
