## 实现与维护

- `HairlineFigure` 接近视口时加载图形，卸载时清理动画与监听；装饰不增加键盘焦点，加载失败不影响文字或操作。
- 10 个在用自定义图形及 1 个清单备选的独立源文件在 `docs/hairline-ui/v2/figures/`。修改后运行 `node scripts/build-hairline-figures.mjs` 生成静态模块。
- 其余图形来自 `@lucasmarkes/hairline@0.3.0`。`public/hairline/kernel.js` 保持上游内核原样，并保留 MIT 许可证。
- 开发环境可打开 `/design/hairline`，或使用 `?design-state=empty` / `?design-state=populated` 对照页面状态。正式构建禁用这些预览入口和参数，正常登录与游客参观继续使用各自数据来源。
