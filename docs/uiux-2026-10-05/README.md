# 首页、共享组件和日报优化

沿用 01 整理优化与 Warm Desk Ledger：今天保留原浅色，日期与时间选择器、饼图沿用现有设计。

## 交付

- [日程与日报预览](agenda-newspaper/index.html)：首页真实安排、日报列表与开合录像。
- [首页前后对比](agenda-newspaper/comparison.html)：同一批演示记录与相同桌面宽度。
- [共享组件交互预览](components/preview.html)：按钮、页签、开关、勾选、输入和折叠区。需运行项目开发服务器。
- [共享组件前后对比](components/comparison.html)：可独立打开的静态对比。

首页按七天显示日程标题、时间和原分类色，手机可在卡片内横向翻阅；点选日程打开对应日期。优先待办继续分为今日待办和其他待办。统计与辅助文字退到次要位置。

生活日报保留档案柜和纸张隐喻，优先显示每期标题、首段摘要与真实配图；搜索保留完整摘要。展开 820ms、收回 620ms，移动和对折共用时间轴。展开中 Esc 可反转当前帧，收回后恢复条目焦点和滚动。减少动态效果时直接切换。

共享控件沿用原设计变量，统一焦点、按压、禁用与错误反馈；页签和导航的选中背景连续移动，移动端更多菜单支持退出时恢复焦点。

## 验证与边界

实现阶段完成一轮独立视觉复核与桌面/390px手机操作走查：日期导航、旧报展开和归位、Esc中断、搜索清空恢复均验证。截图与录像使用虚构演示数据。200%截图和减少动态效果录像也在本地验收。深色模式尚未做运行验收。
