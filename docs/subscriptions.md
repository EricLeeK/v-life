# 订阅服务

入口：用品管理 → 订阅服务，支持直达 `/belongings?tab=subscriptions`。

本次实现覆盖订阅增删改、服务与管理网址、套餐和账号备注、固定或按量价格、CNY/USD/JPY、月/季/年/自定义周期、试用与已结束状态、站内到期提醒、搜索筛选和付款历史。首页用品入口显示需要留意的订阅数量。

## 金额和日期

- 月均固定成本只包含有效订阅，按量估算单列，试用不计入月均。不同币种不直接相加。
- 未来 30 天预计扣款只预测自动续费；逾期未确认的账期不自动跳过。
- 月末账期保留约定日，例如 1 月 31 日 → 2 月月底 → 3 月 31 日。
- 确认付款保存实际金额，不覆盖套餐价格。勾选同时记账时，非人民币必须提供实际汇率。
- 同一订阅同一账期以数据库行锁、唯一约束和请求快照防重复；历史、下一账期及记账在一次事务中完成。
- 关闭续费只改变台账状态。实际取消扣费须前往服务商，站内提醒不等同于手机推送。

## Agent

网页 AI、MCP、Agent API 均接入 `subscription` 和 `subscription_payment`。查询、开放分类、按币种汇总、修改及确认付款的接口和示例见 [Agent 接入说明](agent-access.md)。付款历史仅可查询，确认操作通过专用 RPC 创建，不能直接增改历史表。
