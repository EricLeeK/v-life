# 备考 UI 优化

意图：存量模块 UI 升级；阶段：本地实现与实屏复验完成。使用 oil-ui-pro 0.16.0。

## 方向

品类是日常高频使用的备考工作区。核心对象是需要重新作答的题目，以及有明确日期的考试；用户首先要开始复习，再进入某个考试管理内容。主动作是“作答 → 核对 → 记录错因 → 安排复习”。

选择「专注复盘」：保留 V-Life 暖纸色、衬线标题、既有无衬线正文及绿色语义色。现有 DESIGN.md 的品牌资产成立，上一版的问题主要在大标题、过量垂直空间、同层卡片堆叠和阅读层级，而不是全站视觉规范。此次升级限于备考模块，不更换全局导航、字体或业务模型。

- 北极星：一眼找到下一步，一屏读懂一道题。
- 字体：紧凑衬线页标题；15–16px 的题面正文；等宽计时；衬线倒计时数字。
- 色彩：暖色工作区、白色题纸、淡灰材料区；绿色只用于主动作、选中和正确反馈，红／黄保留明确语义。
- 记忆点：材料与题面构成一张完整的双页题纸；单行选项的字母圈随选择填实；核对后展开解析与个人错因的双栏复盘。

## 结构

首页保留考试与三条错题预览，但复习入口提前；标题和模块导航保持紧凑。桌面待复习数量与题目队列并列，移动端重排为一个紧凑操作条。考试使用短卡片，手机端收为横向行，避免倒计时越多页面越高。

复习页将计时并入题面工具栏，保留题型、知识点和队列位置。资料在桌面与题目并列，手机顺序显示且可折叠。选项为字母圈与正文同一行；带图选项仍为两列，完整保留图形。解析、错误思路和记忆要点使用与笔记相同的 Markdown 渲染引擎，并提供专用于题目阅读的排版变体。

错题库使用一致的模块导航、紧凑筛选、搜索及带序号的题目行。题库／共用材料、连接页和录入表单沿用相同的题纸表面与间距。

## 状态与边界

保留现有提交、CAS、草稿、计时、错因标记、同步失败重试、关联和筛选行为；没有重写数据层或复习算法。禁用、选择、答错、超时、保存及空状态具有独立反馈。焦点可见，支持减少动态效果。

删除重复文案：首屏口号、模块内第二条演示说明、每个区域的功能解释、选项中重复的目标信息。保留全局演示提示、必要的同步／权限说明与操作结果。

## 动效

1. 进入题面：题纸在 360ms 内淡入并向上归位 8px，避免整页飞入。
2. 选择答案：选项背景与字母圈在 180–220ms 内填实，立即反馈选择。
3. 核对答案：复盘区在 320ms 内展开到位，状态先更新再呈现；减少动态效果时直接显示。
