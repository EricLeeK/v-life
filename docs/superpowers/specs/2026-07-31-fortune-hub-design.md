# 运势中枢（中西合璧）设计文档

> **日期：** 2026-07-31  
> **版本：** v1.0  
> **状态：** 待实现  
> **范围：** 今日运势一览 + 中西式互动占卜；轻快娱乐向；规则底稿 + AI 润色

---

## 1. 背景与目标

V-Life 是个人生活管理应用。女朋友希望增加「运势」页面，同时覆盖西式（星座、塔罗、月相）与中式（黄历宜忌、生肖、易经起卦、求签、八字日柱），作为日常轻娱乐入口，而不是严肃命理工具。

### 成功标准

1. 打开运势页能一眼看到「今日专属」总览（基于个人档案）
2. 中式与西式工具均可进入互动流程，结果可保存
3. 黄历 / 月相 / 底分不依赖 AI；解读类文案可走现有 `ai-chat`，失败时有规则降级
4. 设置页「运势档案」默认折叠，不干扰主设置
5. 语气固定为轻快、鼓励、不恐吓；不做医疗 / 投资建议

### 明确不做

- 社交分享、排行榜、多人同盘
- 完整专业八字排盘、合婚、风水布局
- 付费抽次数商城（首版不限次；额度复用托管 AI 现有机制）
- 独立视觉品牌体系（沿用 V-Life，工具页仅局部氛围色）

## 2. 产品形态

### 2.1 信息架构：今日运势中枢

侧栏 / 移动导航新增「运势」，路由前缀 `/fortune`。

**首页 `/fortune` 自上而下：**

1. 日期条（公历 + 农历简写）
2. 专属今日总览：星座 × 生肖合成一句 + 整体 / 爱情 / 事业 / 财运星级
3. 黄历宜忌 + 月相（并排）
4. 西式工具入口：塔罗、星座详解
5. 中式工具入口：易经起卦、求签、生肖运势、八字日柱
6. 次要入口：我的记录

未填写档案时：展示「通用今日」文案 + CTA 引导至设置补生日。

### 2.2 个人档案

存储在 `user_settings.fortune_profile`（JSON），设置页以**折叠面板**展示，**进入设置时默认收起**。

| 字段 | 必填 | 说明 |
|------|------|------|
| `birth_date` | 是（专属运势需要） | 公历生日 `YYYY-MM-DD` |
| `birth_hour` | 否 | 时辰枚举或 0–23 点；影响日柱精度 |
| `birth_place` | 否 | 纯备注，不做真太阳时校正 |
| `zodiac_sign` | 派生 | 由生日计算，允许用户覆盖 |
| `shengxiao` | 派生 | 由生日计算，允许用户覆盖 |

### 2.3 语气

默认轻快娱乐。AI system prompt 约束：温柔鼓励、短句、可执行的小建议；禁止恐吓、诅咒、绝对化断言；结尾可带一句「仅供娱乐」。

## 3. 功能模块

### 3.1 今日一览（规则为主）

| 模块 | 数据来源 | 展示 |
|------|----------|------|
| 黄历宜忌 | 本地规则 / 黄历库（按日期） | 宜、忌各最多 3 项；可选冲煞一行 |
| 月相 | 本地天文近似算法 | 月相名 + 一句轻解读 |
| 星级底分 | 日期 + 星座 / 生肖哈希到 1–5 星 | 确定性，同用户同日不变 |
| 专属短评 | 规则底稿 + AI 扩写 | 按 `user_id + date` 缓存 |

### 3.2 西式互动

**塔罗 `/fortune/tarot`**

1. 选题：感情 / 事业学业 / 今日指引（默认）/ 自定义一句  
2. 抽 3 张（过去 · 现在 · 建议），含正逆位  
3. AI 解读；可再抽、可存记录  

牌组：韦特 78 张；随机需可记录 seed，便于历史复现。

**星座详解 `/fortune/zodiac`**

基于档案星座；规则段落 + AI 扩写；可切换查看其他星座（不改档案）。

**月相**：首版嵌在首页卡片，不单独路由。

### 3.3 中式互动

**易经起卦 `/fortune/iching`**

心念问题 → 一键模拟三枚铜钱起卦 → 本卦 + 变爻 → AI 白话解读。

**求签 `/fortune/lot`**

短动画 → 从签池抽一支（上上～下下）→ 模板签文 + AI 白话。

**生肖运势 `/fortune/shengxiao`**

同星座详解模式；可切换属相浏览。

**八字日柱 `/fortune/bazi`**

读档案生日（+ 时辰）→ 展示日柱与五行简图 → AI「今日提醒」一段。  
不做完整四柱细盘、大运流年恐吓向内容。

### 3.4 历史 `/fortune/history`

个人列表：类型、问题摘要、时间；点进看当时 payload + 解读。无社交。

## 4. 技术设计

### 4.1 路由一览

| 路径 | 页面 |
|------|------|
| `/fortune` | 今日中枢 |
| `/fortune/tarot` | 塔罗 |
| `/fortune/iching` | 易经 |
| `/fortune/lot` | 求签 |
| `/fortune/bazi` | 八字日柱 |
| `/fortune/zodiac` | 星座详解 |
| `/fortune/shengxiao` | 生肖运势 |
| `/fortune/history` | 我的记录 |

导航：`AppSidebar` / `MobileNav` 增加入口；支持 `hidden_features` 隐藏（key：`fortune`）。

### 4.2 前端模块划分

```
src/pages/fortune/
src/components/fortune/     # DailyHero, AlmanacCard, MoonCard, ToolGrid, TarotDeck…
src/lib/fortune/            # almanac, moon, zodiac, shengxiao, tarot, iching, lot, bazi
src/hooks/useFortune.ts     # 档案、今日缓存、readings CRUD
```

视觉：沿用 V-Life 暖灰米纸底与深棕字；塔罗 / 起卦页允许局部深色氛围，不另起品牌色板。

### 4.3 数据模型

**`user_settings.fortune_profile`**（JSONB，可空）

```json
{
  "birth_date": "1998-08-20",
  "birth_hour": 9,
  "birth_place": "",
  "zodiac_sign": "virgo",
  "shengxiao": "tiger"
}
```

**`fortune_daily_cache`**

| 列 | 类型 | 说明 |
|----|------|------|
| `id` | uuid | PK |
| `user_id` | uuid | FK → auth.users，RLS |
| `cache_date` | date | 用户本地日（以客户端日期写入） |
| `payload` | jsonb | 星级、短评、扩写文案等 |
| `created_at` / `updated_at` | timestamptz | |

唯一约束：`(user_id, cache_date)`。

**`fortune_readings`**

| 列 | 类型 | 说明 |
|----|------|------|
| `id` | uuid | PK |
| `user_id` | uuid | RLS |
| `type` | text | `tarot` / `iching` / `lot` / `bazi` / `zodiac` / `shengxiao` |
| `question` | text | 可空 |
| `payload` | jsonb | 牌面、卦象、签号、seed 等 |
| `reading` | text | 展示用解读正文 |
| `created_at` | timestamptz | |

RLS：用户仅能读写自己的行。

### 4.4 AI 混合策略

复用现有 `ai-chat` Edge Function，通过请求体区分场景（例如 `mode: "fortune"` 或专用 prompt 前缀），服务端注入运势 system prompt。

```
规则引擎产出结构化事实（牌/卦/宜忌/星级）
    → 若 AI 可用：生成润色文案 → 写入 cache / 展示
    → 若失败或额度用尽：展示规则底稿 + 可读错误（沿用 aiErrors）
```

今日总览类文案优先读 `fortune_daily_cache`，避免同日重复消耗额度。

### 4.5 确定性与随机

- 同用户同日的星级 / 黄历展示：纯日期与档案派生，结果稳定。  
- 塔罗 / 起卦 / 求签：每次互动生成 `seed`，写入 `payload`，历史可复现牌面。  
- 不在服务端重放动画，只存结果快照。

### 4.6 错误与降级

| 情况 | 行为 |
|------|------|
| 未填生日 | 通用今日 + 引导设置 |
| AI 失败 / 托管额度用尽 | 规则底稿 + 提示可填自己的 Key 或稍后重试 |
| 黄历库缺失某日 | 显示「宜：平日行事；忌：无」类保守默认，不白屏 |
| 保存记录失败 | toast 错误，解读仍留在当前页可复制 |

## 5. 实现顺序（建议分 PR）

1. Migration（profile 字段 + 两张表）+ 设置折叠区 + 侧栏入口 + 今日中枢（规则部分）  
2. 星座 / 生肖详解 + AI 扩写 + 当日缓存  
3. 塔罗（优先的明星互动）  
4. 求签 + 易经起卦  
5. 八字日柱 + 历史页  

规格覆盖全部模块；代码可按上表拆分合并，不必单 PR 一次上线。

## 6. 测试要点

- 档案：填写 / 清空后首页专属与通用切换正确；设置默认折叠  
- 今日缓存：同日第二次进入不重复打 AI（可 mock）  
- 塔罗：seed 复现三张牌与正逆位一致  
- AI 降级：断开或 429 时仍展示底稿  
- RLS：用户 A 无法读用户 B 的 `fortune_readings`  
- `hidden_features` 含 `fortune` 时导航与路由守卫行为与其它模块一致  

---

## 7. 设计决策摘要

| 决策 | 选择 | 理由 |
|------|------|------|
| 形态 | 今日中枢 + 工具入口 | 每天有收获，互动不抢戏 |
| 模块范围 | 中西式 7 项全收 | 产品完整；实现可分期 |
| 文案 | 规则 + AI 混合 | 稳定底盘 + 有温度的解读 |
| 档案 | 完整档案，设置默认收起 | 个性化与设置页清爽兼得 |
| 语气 | 轻快娱乐 | 符合女朋友使用场景 |
| 视觉 | 贴合 V-Life + 工具页局部深色 | 不另起品牌 |
