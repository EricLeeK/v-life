# 视频拖拽看板复刻

目标：独立复刻用户提供的 Akash 视频，保留四列、十二张任务卡、英文内容、渐变封面和速度驱动的轻微倾斜。

视觉权威：用户提供的视频及其配文；不用 V-Life 的暖色主题替换视频的中性灰白画面。参考帧 1910 × 1080，外框约 (124,124)–(1786,956)，卡片宽约 346，高 106，带封面卡高 184。所有比例按视口缩放，窄屏保留可横向浏览的列宽。

文件边界：只创建 `public/drag-weight/`、`scripts/drag-weight/` 和本计划，不修改现有应用入口、路由、数据或用户未提交的文件。入口 `/drag-weight/`，也可独立静态托管。

实现顺序：

- [ ] 写 `scripts/drag-weight/physics.test.mjs`，先验证速度决定倾斜、4.5° 硬限幅、无新指针事件时回正、不同帧率下的收敛和跨列排序不丢卡。
- [ ] 实现 `public/drag-weight/physics.mjs` 与 `board-model.mjs`。阻尼弹簧跟随坐标；倾斜目标由逐帧横向速度驱动；帧时间有上限并采用子步积分。
- [ ] 实现独立 HTML、CSS、`app.mjs`。复用源视频截取的三张封面；文字、图标、卡片和布局为真实 DOM。
- [ ] 指针捕获和拖动阈值；悬浮卡、占位、FLIP 让位、释放归位；支持 Escape 取消、键盘搬运、触屏边缘横向滚动、减少动画、刷新保留及重置。
- [ ] Node 单测通过，真实浏览器验证拖拽前后、快慢倾斜、停手回正、取消、空列和手机横向浏览。桌面和手机截图，原视频同尺寸对照，集中修正。
- [ ] 运行设计检测，独立审查并记录交付，打开本地可交互预览。

验收限制：录屏不提供源字体、原始弹簧参数或浏览器缩放；可验证画面近似程度和行为，但不能声称源码级或逐像素绝对相同。视频中的放大和视口平移视为录屏取景，不把它强加为页面自动镜头运动。
